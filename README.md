# Implicit UI

Small, practical improvements for Unity UI (uGUI), built on one rule: adding the component should be
enough. No material to drag in, no setup prefab, no central asset to configure.

> **Status: in development.** Nothing is released yet, and the API may change until 1.0.0.

## Planned for 1.0

- **Implicit Fill** - fill an Image that stays Sliced or Tiled, so a framed health bar can be resized.
- **Implicit Grayscale** - a disabled button turns gray on its own, with no material to set up.
- **Implicit Hitbox** - a touch target larger than the visual, including a minimum finger size.
- **Implicit Text Size Group** - sibling texts share the smallest auto size, so a menu stays consistent.
- **Font Changer** - swap fonts across open scenes or a folder of prefabs, with a preview before anything changes.
