# Implicit UI

Small, practical improvements for Unity UI (uGUI), built on one rule: adding the component should be enough.

- **Implicit Fill** - fills an Image that stays Sliced or Tiled, so a framed bar keeps its corners.
- **Implicit Grayscale** - an Image turns gray on its own while its button is not interactable.
- **Implicit Hitbox** - a minimum touch size in dp, plus an alpha hit test that works with atlases.
- **Implicit Text Size Group** - sibling labels share the smallest auto size any of them would pick.
- **Font Changer** - `Tools > Implicit UI > Font Changer` swaps fonts across scenes and prefabs, after a dry run.

Samples for each feature are in the Package Manager window.

Full documentation, screenshots and support: https://github.com/bionics07/Implicit-UI
